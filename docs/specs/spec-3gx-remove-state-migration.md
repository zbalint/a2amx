## 1. Why

`src/migrate.rs` (858 lines) exists only to move a v0.3 state directory into the v0.4.0 root layout once. The owner confirmed it is no longer needed. Keeping it costs 18 `cs` findings, two test files and a code path run on every `daemon start`, `gateway token` and `gateway up`.
